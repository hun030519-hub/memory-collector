# Memory Collector — 웹 체험판

ai응용게임및프로그래밍 과제《메모리 콜렉터》를 바탕으로 제작한 **GitHub Pages 배포용 정적 웹사이트**입니다.

## 들어 있는 콘텐츠

- 게임 소개, 세계관, 기억 앨범, 조작 안내
- **실제로 플레이 가능한 3개 리듬 미니게임**: 퇴근길 댕댕이의 마중(Tap/Hold), 빗속의 댄스(Tap), 톡! 톡! 팝콘 데이트(Tap)
- 1버튼/1터치 판정(Perfect / Good / Miss), 콤보, 점수, 등급
- 성공할수록 흑백에서 컬러로 변화하는 기억 복원 연출
- 체험 결과와 수집 기록을 브라우저 `localStorage`에 보관
- 외부 라이브러리·CDN·빌드 과정 불필요; 음악은 Web Audio API로 실시간 생성

## 키보드 / 터치

- **PC:** `Space`를 리듬에 맞춰 누르기. 댕댕이 스테이지의 마지막은 약 0.9초 길게 누르기.
- **모바일:** 게임 화면을 손가락으로 터치. 마지막 HOLD는 길게 터치.
- **일시정지:** 게임 상단 버튼 또는 `Esc`.
- **사운드:** 상단 사운드 버튼. 브라우저의 정책에 따라 첫 사용자 클릭 후 소리가 활성화됩니다.

첫 비트까지 카운트다운 3초, 이후 약 14개 입력을 진행합니다. 한 판은 약 14초입니다.

## 구성

```
index.html           사이트 구조 및 접근성 텍스트
styles.css           스타일과 반응형 UI
game.js              실시간 Canvas 장면·Web Audio·판정·점수·저장
assets/              기존 기획 시안 및 아이콘
.nojekyll            GitHub Pages Jekyll 처리 우회
```

## 향후 개선

- 미니게임별 고유 리듬 패턴/씬 전환 보강 및 스테이지 난이도 설정
- 오리지널 BGM과 효과음 제작
- 리듬 입력 타이밍 가시성 작업
- 오리지널 bgm에 맞는 클릭 타이밍 조절

*본 결과물은 소개 사이트 + 브라우저에서 작동하는 게임 프로토타입이며, 완제품이나 서버 연동 게임이 아닙니다.*
