# Memory Collector — 웹 체험판

ai응용게임및프로그래밍 과제《메모리 콜렉터》를 바탕으로 제작한 **GitHub Pages 배포용 정적 웹사이트**입니다.

## 들어 있는 콘텐츠

- 게임 소개, 세계관, 기억 앨범, 조작 안내
- **실제로 플레이 가능한 3개 리듬 미니게임**: 퇴근길 댕댕이의 마중(Tap/Hold), 빗속의 댄스(Tap), 톡! 톡! 팝콘 데이트(Tap)
- 1버튼/1터치 판정(Perfect / Good / Miss), 콤보, 점수, 등급
- 성공할수록 흑백에서 컬러로 변화하는 기억 복원 연출
- 체험 결과와 수집 기록을 브라우저 `localStorage`에 보관
- 외부 라이브러리·CDN·빌드 과정 불필요; 음악은 Web Audio API로 실시간 생성

## 실행하기

`index.html`을 브라우저에서 열거나, 로컬 웹서버로 실행합니다.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다.

## GitHub Pages 배포하기

1. GitHub에서 새 **Public repository**를 생성합니다. 예: `memory-collector`.
2. 이 폴더의 모든 파일과 `assets` 폴더를 **저장소 루트**에 업로드합니다. (`index.html`이 루트에 있어야 합니다.)
3. GitHub의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. **Branch: main / (root)**를 지정하고 저장합니다.
5. 게시가 완료되면 `https://깃허브아이디.github.io/memory-collector/`에서 실행됩니다.

외부 빌드 도구가 필요하지 않습니다. 저장소 이름을 바꾸어도 모든 이미지·스크립트가 상대 경로이므로 작동합니다.

## 키보드 / 터치

- **PC:** `Space`를 리듬에 맞춰 누르기. 댕댕이 스테이지의 마지막은 약 0.9초 길게 누르기.
- **모바일:** 게임 화면을 손가락으로 터치. 마지막 HOLD는 길게 터치.
- **일시정지:** 게임 상단 버튼 또는 `Esc`.
- **사운드:** 상단 사운드 버튼. 브라우저의 정책에 따라 첫 사용자 클릭 후 소리가 활성화됩니다.

첫 비트까지 카운트다운 3초, 이후 약 14개 입력을 진행합니다. 한 판은 약 14초입니다.

## 구성


## 향후 개선

- 미니게임별 고유 리듬 패턴/씬 전환 보강 및 스테이지 난이도 설정
- 새로운 오리지널 BGM과 효과음 제작
- 튜토리얼, 세밀한 HOLD 판정, 모바일 기기별 입력 보정
- 별도 캐릭터 스프라이트, 기억 복원 애니메이션 고도화
